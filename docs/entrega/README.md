# Entrega — Desafío Digital ExpoJuy 2026

Este directorio reúne la documentación de primera etapa y la evidencia del prototipo navegable.

## Contenido

| Archivo | Uso |
| --- | --- |
| `memoria-descriptiva.pdf` | Documento de presentación requerido. |
| `memoria-descriptiva.html` | Fuente editable e imprimible de la memoria. |
| `declaracion-uso-ia.md` | Declaración de herramientas y límites de IA. |
| `manual-ejecucion.md` | Ejecución y verificación local. |
| `enlaces-entrega.md` | Control de enlaces y datos a completar antes de enviar. |
| `evidencia/` | Capturas verificadas de escritorio y móvil, con nota de contexto. |

## Control previo al envío

1. Completar las referencias marcadas como `PENDIENTE DE COMPLETAR`.
2. Adjuntar la memoria PDF y declarar el enlace al mockup o prototipo en el formulario oficial.
3. Enviar antes del **8 de septiembre de 2026 a las 23:59 horas, hora oficial de la República Argentina**.
4. Conservar disponibilidad para el Demo Day del **14 de septiembre de 2026** si el equipo resulta preseleccionado.

La propuesta es conceptual y visual. El prototipo navegable acompaña la presentación, pero no constituye un sitio operativo ni reemplaza las definiciones institucionales posteriores.
